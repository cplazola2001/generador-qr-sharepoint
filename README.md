# Generador QR — SharePoint

## Description

This is a Python-based app that generates QR codes from URLs.

It was created to help the Seventh District Court in Administrative Matters in Jalisco, Mexico, share document links with public authorities without relying on third-party QR code generators that could potentially expose sensitive information. The app is designed to work alongside SharePoint, allowing users to manage document access and privacy settings through the platform.

Its simple and practical design makes it accessible to users with different levels of technical experience. The app can be downloaded as a .zip file and run on Windows without requiring users to install Python or additional libraries.

## Descripción general

Esta aplicación, desarrollada en Python, permite generar códigos QR a partir de enlaces URL.

Fue creada para facilitar que el Juzgado Séptimo de Distrito en Materia Administrativa en Jalisco comparta enlaces a documentos con distintas autoridades, sin depender de generadores de códigos QR de terceros que podrían exponer información personal. La aplicación está diseñada para utilizarse junto con SharePoint, permitiendo que los usuarios administren los permisos de acceso y la privacidad de los documentos desde dicha plataforma.

Su diseño es sencillo, práctico y accesible para usuarios con distintos niveles de conocimientos técnicos. La aplicación puede descargarse como archivo .zip y ejecutarse en Windows sin necesidad de instalar Python ni bibliotecas adicionales.

### Features

1. Easy

No Python or programming knowledge required. Just copy and paste your document's URL, choose a filename, and select where to save your QR code. That's it!

2. Portable

The app comes in a ZIP file that can be stored on a USB drive or shared with other users. Simply extract the files and run the application on a compatible Windows computer. No Python installation needed.

3. Privacy-focused

No need to paste potentially sensitive document links into third-party QR code generators. QR codes are generated locally, while document access and sharing permissions remain managed through SharePoint.

4. Free to use

No subscriptions, API tokens, or paid QR code generation services required. Just a simple, practical tool that gets the job done.

### Características

1. Fácil de usar

No necesitas conocimientos de Python ni programación. Solo copia y pega el enlace de tu documento, escribe el nombre del archivo y selecciona dónde guardar tu código QR. ¡Así de sencillo!

2. Portátil

La aplicación se distribuye mediante un archivo ZIP que puedes almacenar en una memoria USB o compartir con otros usuarios. Solo necesitas extraer los archivos y ejecutar el programa en una computadora Windows compatible, sin instalar Python.

3. Enfocado en la privacidad

No necesitas introducir enlaces potencialmente sensibles en generadores de códigos QR de terceros. Los códigos se generan localmente, mientras que los permisos de acceso y uso compartido de los documentos se administran desde SharePoint.

4. Gratuito

Sin suscripciones, tokens de API ni servicios de generación de QR de pago. Una herramienta sencilla, práctica y eficaz que cumple con su propósito.

#### Installation

To use Generador QR, all you need is a compatible Windows computer. No Python installation required!

1. Go to the Releases section of this repository and select the latest available version.

2. Look for the Assets section and download GeneradorQR-Windows.zip.

3. This ZIP file contains everything you need to run the program. Just extract its contents using Windows' built-in ZIP extractor or a tool like 7-Zip.

4. Once extracted, find GeneradorQR.exe and double-click it. Make sure to keep the accompanying _internal folder in the same location.

5. That's it! You can now paste your document links, generate QR codes, and add them to your documents.

#### Instalación

Para utilizar el Generador QR, solamente necesitas una computadora compatible con Windows y seguir estos pasos:

1. Ve a la sección Releases de este repositorio y selecciona la última versión disponible.

2. Busca el apartado Assets y descarga el archivo GeneradorQR-Windows.zip.

5. ¡Listo! Ya puedes pegar los enlaces de tus documentos, generar códigos QR y agregarlos a tus oficios.
